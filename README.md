# Quick Sort

A C++ implementation of the quick sort algorithm.

## Complexity

- Average time: `O(n log n)`
- Worst-case time: `O(n^2)`
- Space: `O(log n)` average recursion stack

## Compile

```bash
g++ Quick_sort.cpp -o Quick_sort
```

## Run

```bash
./Quick_sort
```

Enter the number of elements followed by the elements on the next input line.

```text
5
64 25 12 22 11
11 12 22 25 64
```
